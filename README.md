# Instruction to reproduce results in METAHICT paper

Scripts used to reproduce the plots in the manuscript *METAHICT enables comprehensive and flexible genome-resolved microbiome analysis with metagenomic Hi-C* are organized below by METAHICT module.

## 6. Binning Module

- `binning_result.py` — Script for Fig. 2.
- `ensemble_methods.py` — Script for Fig. S1.
- `non_hic_binners.py` — Script for Fig. S2.
- `sankey_stats.py` — Script for Fig. 4 and Fig. S4.

## 7. Reassembly Module

- `all_pies.py` — Script for Fig. 5.
- `bin_quality.py` — Script for Fig. S5.

## 9. Annotation Module

- `annotation_binning.py` — Script for Fig. 3.
- `supp_annotation_binning.py` — Script for Fig. S3.
- `phylum_stacked.py` — Script for Fig. 6A.
- `dissimilarity.py` — Script for Fig. 6B.

## 10. MGE Module

- `fae_mags_heatmap.py` — Script for Fig. 6D.
- `phylum_contact_bar.py` — Script for Fig. 6E.
